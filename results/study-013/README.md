# Study 013 data: magnetic reduced energy

**Author: Biswajit Jana · 23 November 2026**

All values are deterministic theoretical calculations based on [MMP v3 Eq. (5.47)](https://arxiv.org/html/1807.04726v3), not observations. See the [report](../../reports/015-magnetic-support-and-separation.md) for the model, independent derivations, limitations and provenance.

Natural units ℏ = c = 1. s = d/d₀, y = πℓ/d, e = 6dE/(πq). f = exterior field-line length/d. ν is the field-line label in (0,2]; it is unrelated to Study 010's mass parameter. q is the integer flux; g is the gauge coupling. No quantity is converted to seconds or meters.

Each has an SVG counterpart in the same directory. Plot curves and independent checks are saved; no observed error distribution is assumed.

Run `scripts/run_magnetic_study.py`, then `scripts/verify_magnetic_study.py` using the repository virtual environment. Inner and outer production quadrature orders are 512. The small-separation audit deliberately uses endpoint-adaptive integration instead of assuming that the main fixed-node grid resolves a different asymptotic regime. The normalized coefficient is still approaching its leading limit at the smallest saved s; the leading coefficient is not fitted from those data.

Tiny refinement differences near floating-point precision do not bound the modeling error. At extreme s the formal reduced functional can be evaluated outside the controlled physical regime; the graphs do not identify every plotted point with a viable spacetime. No complete perturbation solver, running gauge coupling, finite-charge state, physical detector or astronomical dataset is included.
