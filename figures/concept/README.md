# Conceptual hero

**Project author: Biswajit Jana**

## Current realistic hero

`wormhole-camera-hero.png` is the current README hero, generated on 10 November 2026 in response to a request for a more realistic camera appearance. The reference was the independently calculated image `figures/study-003/02-camera-with-legends.png`. It preserves the conceptual distinction between light from the other end, winding/distorted images and our-side sky, while replacing procedural sky textures with a photorealistic visual interpretation. It is **not pixel-accurate ray tracing**, detector data or a prediction of the actual colors and sources of a physical wormhole.

The visible title, subtitle and footer identify it as hypothetical and model-inspired. Legends A, B and C explain the depicted regions. The author credit is Biswajit Jana. The exact numerical image and equations remain available in the [camera report](../../reports/006-what-a-wormhole-could-look-like.md).

Prompt brief: edit the calculated camera reference into a photorealistic scientific hero; preserve a star-filled circular window and surrounding distorted/repeated images; use restrained realistic starlight; exclude a featureless event horizon, funnel mesh, material surface, accretion disk and spacecraft; retain clear hypothetical labeling and three explanatory legends. Generation changes fine image structure, so measurements must be taken from the scientific outputs, never this artwork.

## Earlier conceptual illustration

`wormhole-wave-hero.png` is an AI-assisted conceptual illustration generated for this repository on 10 November 2026. It depicts a hypothetical throat and waves. It is not astronomical evidence, a numerical solution, an exact embedding, or a scientific data plot. Its color and wave spacing carry no quantitative meaning.

The image was generated using the built-in image-generation tool and copied into the repository. Prompt brief: a dark navy editorial illustration, a fine ivory/cyan mesh connecting two flared ends, amber and cyan wave fronts, negative space, no equations, labels, spacecraft or accretion disk. Scientific plots remain independently generated from saved numerical data and scripts.
